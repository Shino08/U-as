# Glamour Booking Suite

Eres un desarrollador frontend especializado en aplicaciones web modernas e interactivas. Tu tarea es crear una landing page dinámica y de alto impacto visual para un negocio de servicios de uñas, que integre un sistema de agendamiento de citas con un catálogo de servicios en tiempo real.

**Objetivo principal:**

Construir una single-page application (SPA) moderna enfocada en el sector de nail art/servicios de uñas que permita a los usuarios explorar un catálogo de servicios, seleccionar tratamientos, agendar citas de forma fluida en vivo, todo en una experiencia visual cautivadora y orientada a captar clientes.

**Requisitos funcionales:**

1. **Sección de Catálogo en Vivo**

   - Galería/grid interactiva de servicios de uñas (manicura, pedicura, nail art, extensiones, etc.)

   - Selección en tiempo real con feedback visual inmediato

   - Los usuarios pueden hacer clic para ver detalles del servicio y proceder a reservar

   - Integración fluida entre la selección del catálogo y el sistema de agendamiento

2. **Sistema de Agendamiento de Citas**

   - Formulario dinámico para capturar datos (nombre, email, teléfono, fecha, hora)

   - Calendario integrado que muestre disponibilidad de franjas horarias

   - Confirmación inmediata tras agendar la cita

   - Debe funcionar integrado con la selección previa del servicio desde el catálogo

3. **Experiencia Visual Premium**

   - Animaciones smooth en motion (transiciones fluidas entre secciones)

   - Efectos de scroll (parallax, fade-in, reveal animations, sticky elements)

   - Componentes visuales llamativos (tarjetas de servicios, botones interactivos, efectos hover)

   - Diseño moderno y limpio, responsive en dispositivos móviles y desktop

   - Microinteracciones que refuercen cada acción del usuario

**Requisitos técnicos:**

- Stack moderno: React/Next.js (o Vue/Nuxt si lo prefieres) + Tailwind CSS o similar

- Librerías recomendadas para animaciones: Framer Motion, AOS (Animate on Scroll), o GSAP

- Estado manejado eficientemente (Context API, Zustand, o Pinia)

- Estructura escalable y componentizada

- Código limpio, bien documentado y listo para producción

**Estructura sugerida:**

- Header/Navbar fijo o sticky

- Sección hero con call-to-action orientado a captar clientes

- Catálogo interactivo de servicios de uñas con filtros opcionales

- Panel de agendamiento (modal o sección dedicada) integrado con la selección del catálogo

- Footer con información de contacto

- Toda la navegación debe ser intuitiva y visual

**Entregables:**

- Código completo y funcional (componentes principales + estilos)

- Instrucciones claras para ejecutar el proyecto localmente

- Explicación de cómo personalizar el catálogo de servicios de uñas y las franjas horarias disponibles

- Guía para adaptar colores, imágenes y textos al branding específico del negocio de nail art

Crea una experiencia que sea moderna, rápida, visualmente impactante y que mantenga al usuario enganchado desde el primer scroll, con énfasis en la captura de clientes para un negocio de servicios de uñas.
